# 🔊 Phonics Trainer — ฝึกออกเสียงภาษาอังกฤษแบบโฟนิกส์ พร้อมบันทึกคะแนน

เว็บแอปสำหรับฝึกอ่านออกเสียงภาษาอังกฤษตามหลัก **Phonics** ผู้เรียนกดฟังเสียงตัวอย่าง
กดไมค์แล้วออกเสียงตาม ระบบจะให้คะแนน 0–100 บอกว่าเสียงไหนเพี้ยน และ**บันทึกคะแนนทุกครั้งลงฐานข้อมูล**
เพื่อดูความก้าวหน้าย้อนหลังได้

เขียนด้วย **Flask ไฟล์เดียว** (`app.py`) หน้าเว็บใช้ **Tailwind CSS ผ่าน CDN** ไม่ต้อง build อะไรเลย

## 3. วิธีใช้งาน 5 ขั้นตอน

1. **ใส่ชื่อผู้เรียน** — หน้าต่างแรกจะให้กรอกชื่อ ชื่อนี้ใช้แยกคะแนนของแต่ละคน
   และถูกจำไว้ในเบราว์เซอร์ (localStorage) กดที่ชื่อมุมขวาบนเพื่อสลับผู้เรียนได้ตลอด
2. **เลือกกลุ่มเสียง** — เลือกจาก 6 กลุ่มด้านบน แต่ละกลุ่มมีเคล็ดลับการออกเสียงกำกับไว้
3. **เลือกคำศัพท์** — กดการ์ดคำที่อยากฝึก ระบบจะอ่านตัวอย่างให้ฟังทันที
4. **ฝึกออกเสียง** — ในแผงฝึกจะมีปุ่ม
   - 🔈 **ฟังเสียง** — ฟังคำเต็มความเร็วปกติ
   - 🐢 **ฟังแบบช้า** — ฟังแบบช้าลงสำหรับแกะเสียง
   - **หน่วยเสียงย่อย** — กดที่ช่อง `bl` `a` `ck` เพื่อฟังเสียงนั้นเดี่ยว ๆ
   - 🎤 **กดแล้วพูด** — กดแล้วออกเสียงคำนั้น (ครั้งแรกเบราว์เซอร์จะขออนุญาตใช้ไมค์ ให้กด "อนุญาต")
5. **ดูผล** — ระบบแสดงคะแนนเป็นวงกลม บอกว่าได้ยินเป็นคำอะไร และแนะนำว่าควรแก้เสียงตรงไหน
   คะแนนถูกบันทึกอัตโนมัติ แผงด้านขวาจะอัปเดตทันที

> 💡 ถ้าไมค์ใช้ไม่ได้ กดลิงก์ **"ไมค์ใช้ไม่ได้? พิมพ์คำที่อ่านแทน"** ใต้ปุ่มไมค์
> เพื่อพิมพ์คำที่อ่านเข้าไปแทน เหมาะกับการทดสอบระบบหรือใช้ในห้องที่เสียงดัง

## 4. บทเรียนที่มีให้ (6 กลุ่ม 48 คำ)

| กลุ่ม | เนื้อหา | ตัวอย่างคำ |
|---|---|---|
| 🔤 สระเสียงสั้น (CVC) | พยัญชนะ + สระสั้น + พยัญชนะ | cat, bed, pig, dog, sun, map, hen, fox |
| 👯 ตัวอักษรคู่ (Digraphs) | สองตัวอักษรได้เสียงใหม่หนึ่งเสียง | ship, chin, thin, that, whale, phone, ring, duck |
| 🧩 พยัญชนะควบ (Blends) | สองตัวติดกันแต่ได้ยินครบทั้งคู่ | black, frog, stop, swim, plant, grass, clock, brush |
| ✨ Magic E | e ท้ายคำเงียบ ทำให้สระข้างหน้ายาว | cake, bike, home, cute, note, five, rope, name |
| 🤝 สระคู่ (Vowel Teams) | สระสองตัวอยู่ด้วยกัน | rain, boat, feet, team, night, book, moon, cloud |
| 🚗 สระผสม R | สระที่ถูก r กลืนเสียง | car, bird, horn, farm, turn, star, corn, girl |

### เพิ่ม / แก้คำศัพท์เอง

แก้ที่ตัวแปร `LESSONS` ใน `app.py` รูปแบบข้อมูลเป็นแบบนี้

```python
{"w": "cat", "ipa": "/kaet/", "th": "แมว",
 "ph": [["c", "/k/"], ["a", "/ae/"], ["t", "/t/"]]},
```

- `w` คำศัพท์ (ตัวพิมพ์เล็ก) &nbsp;•&nbsp; `ipa` คำอ่าน &nbsp;•&nbsp; `th` คำแปลไทย
- `ph` คือการแยกหน่วยเสียง แต่ละคู่คือ `[ตัวสะกด, เสียง]` ใช้ทำปุ่มฟังเสียงย่อย

ถ้าใช้เสียงใหม่ที่ยังไม่มีตัวอย่าง ให้เพิ่มคีย์ลงในตาราง `SOUND_DEMO`
ในส่วน JavaScript ด้วย (เช่น `sh:'shhh'`) มิฉะนั้นการกดปุ่มเสียงย่อยจะอ่านทั้งคำแบบช้าแทน

## 5. ระบบให้คะแนนทำงานอย่างไร

ระบบ **ไม่ได้เทียบที่ตัวสะกด แต่เทียบที่หน่วยเสียง** เพราะหัวใจของโฟนิกส์คือเสียง
ฟังก์ชัน `to_phonemes()` จะแปลงคำเป็นสายหน่วยเสียงก่อนเทียบ เช่น

```
thin  ->  Tin        cake  ->  kAk        knight  ->  nYt
tin   ->  tin        cook  ->  kUk        night   ->  nYt
```

จากนั้นคิดคะแนนตามกฎนี้

| กรณี | คะแนน |
|---|---|
| ถอดเสียงได้ตรงคำ | 88 + (12 × ความมั่นใจของระบบ) → พูดชัดมากได้ ~99 |
| คนละคำแต่หน่วยเสียงตรงกัน (คำพ้องเสียง เช่น night / knight) | 92 |
| ไม่ตรง | ความคล้ายของหน่วยเสียง ยกกำลัง 1.5 (ไม่ใจดีเกินไป) |
| ขาดหรือเกินหน่วยเสียง (เช่น black อ่านเป็น back) | หักเพิ่ม 8 |
| โครงพยัญชนะยังถูกทั้งหมด | ได้พื้นขั้นต่ำ 45 กันท้อ |
| คำที่ตรงมาจากตัวเลือกสำรองของระบบ | หักลำดับละ 2 (สูงสุด 6) |

ตัวอย่างผลจริง

| เป้าหมาย | ระบบได้ยิน | คะแนน | คำแนะนำที่แสดง |
|---|---|---|---|
| thin | thin | 99 | ยอดเยี่ยม |
| night | knight | 92 | เสียงถูกแล้ว ระบบแค่ถอดเป็นคำพ้องเสียง |
| plant | pant | 76 | ออกเสียง 'pl' ไม่ครบ ลองเน้นเสียงต้นคำ |
| black | back | 71 | ออกเสียง 'bl' ไม่ครบ ลองเน้นเสียงต้นคำ |
| cat | cut | 54 | พยัญชนะถูกหมดแล้ว เหลือเสียงสระตรงกลาง |
| thin | tin | 54 | ออกเสียง 'th' ไม่ครบ ลองเน้นเสียงต้นคำ |

**เกณฑ์ระดับ** — 90+ ยอดเยี่ยม / 75–89 ดีมาก / 60–74 พอใช้ / ต่ำกว่า 60 ลองใหม่
คำที่เคยทำได้ **85 คะแนนขึ้นไป** จะถือว่า "ผ่าน" และขึ้นเครื่องหมาย ✓ บนการ์ดคำ
(ปรับได้ที่ตัวแปร `PASS_SCORE`)

## 6. คะแนนถูกเก็บที่ไหน

เก็บใน SQLite ไฟล์ `phonics.db` ตาราง `attempts` หนึ่งแถวต่อการฝึกหนึ่งครั้ง

| คอลัมน์ | ความหมาย |
|---|---|
| `user_name` | ชื่อผู้เรียน |
| `group_id` | กลุ่มโฟนิกส์ของคำนั้น |
| `word` | คำที่ฝึก |
| `heard` | ข้อความที่ระบบถอดเสียงได้ |
| `score` | คะแนน 0–100 |
| `confidence` | ความมั่นใจของตัวรู้จำเสียง |
| `created_at` / `created_day` | เวลาและวันที่ (ใช้คำนวณ streak) |

เปิดดูตรง ๆ ด้วยคำสั่งนี้ก็ได้

```bash
python -c "import sqlite3;[print(r) for r in sqlite3.connect('phonics.db').execute('SELECT created_at,user_name,word,heard,score FROM attempts ORDER BY id DESC LIMIT 20')]"
```

หรือกดปุ่ม **⬇️ ส่งออก CSV** ในหน้าเว็บเพื่อเอาไปเปิดใน Excel (ไฟล์เป็น UTF-8 มี BOM
เปิดภาษาไทยได้ไม่เพี้ยน)

## 7. รายการ API

| Method | เส้นทาง | หน้าที่ |
|---|---|---|
| `GET` | `/` | หน้าเว็บทั้งหมด |
| `GET` | `/api/lessons` | บทเรียนทั้งหมด + เกณฑ์ผ่าน |
| `POST` | `/api/attempt` | ส่งผลการออกเสียง → ตรวจ ให้คะแนน บันทึก และคืนสถิติล่าสุด |
| `GET` | `/api/stats?user=ชื่อ` | สรุปสถิติของผู้เรียน |
| `GET` | `/api/history?user=ชื่อ&limit=50` | ประวัติย้อนหลัง |
| `GET` | `/api/leaderboard` | อันดับผู้เรียน (ต้องฝึกอย่างน้อย 3 ครั้ง) |
| `POST` | `/api/reset` | ล้างคะแนนของผู้เรียนคนนั้น |
| `GET` | `/api/export.csv?user=ชื่อ` | ดาวน์โหลดคะแนนเป็น CSV |

ตัวอย่างเรียก `/api/attempt`

```json
{
  "user": "น้องมะปราง",
  "word": "black",
  "heard": "back",
  "alternatives": ["black", "bag"],
  "confidence": 0.72
}
```

ตอบกลับ

```json
{
  "word": "black", "score": 95, "level": "excellent",
  "title": "ยอดเยี่ยม!", "passed": true,
  "matched": "black",
  "hint": "", "stats": { "total": 12, "avg": 79.2, "mastered": 6 }
}
```

ในตัวอย่างนี้ระบบได้ยินเป็น `back` แต่ `black` อยู่ในตัวเลือกสำรองลำดับที่ 1
จึงให้คะแนนจากตัวเลือกนั้นแล้วหักลำดับ 2 คะแนน (88 + 12 × 0.72 − 2 = 95)
หน้าเว็บจะบอกไว้ใต้ผลลัพธ์ด้วยว่า "ให้คะแนนจากตัวเลือกที่ใกล้ที่สุดของระบบ: black"

## 8. แก้ปัญหาที่พบบ่อย

**กดไมค์แล้วไม่มีอะไรเกิดขึ้น / ขึ้นว่าเบราว์เซอร์ไม่รองรับ**
ใช้ Chrome หรือ Edge เท่านั้น Firefox กับ Safari ยังไม่รองรับ Web Speech Recognition

**ขึ้นว่า "ยังไม่ได้อนุญาตให้ใช้ไมโครโฟน"**
กดไอคอนรูปกุญแจ/ไมค์ที่แถบที่อยู่ของเบราว์เซอร์ แล้วอนุญาตให้ `127.0.0.1` ใช้ไมโครโฟน

**เปิดจากมือถือหรือเครื่องอื่นแล้วไมค์ไม่ทำงาน**
เบราว์เซอร์ยอมให้ใช้ไมค์เฉพาะ `https://` หรือ `localhost` ถ้าจะใช้ข้ามเครื่องต้องทำ HTTPS
หรือใช้เครื่องมือ tunnel เช่น `ngrok http 5000` แล้วเข้าผ่านลิงก์ https ที่ได้

**ขึ้นว่า "การเชื่อมต่ออินเทอร์เน็ตมีปัญหา"**
ตัวรู้จำเสียงของ Chrome ประมวลผลบนเซิร์ฟเวอร์ ต้องต่อเน็ตขณะใช้งาน

**หน้าเว็บขาวหรือสไตล์ไม่ขึ้น**
Tailwind โหลดจาก CDN ถ้าเน็ตไม่ถึง `cdn.tailwindcss.com` หน้าจะไม่มีสไตล์

**ไม่ได้ยินเสียงตัวอย่าง**
ตรวจว่าเครื่องไม่ได้ปิดเสียง และในเครื่องมีเสียงภาษาอังกฤษติดตั้งอยู่
(Windows: Settings → Time & language → Speech → เพิ่ม English voice)

**รันแล้ว error `UnicodeEncodeError` ตอนพิมพ์ข้อความไทย**
เวอร์ชันนี้แก้ไว้แล้วโดยบังคับ stdout เป็น UTF-8 ถ้ายังเจอ ให้ตั้งตัวแปรนี้ก่อนรัน
— PowerShell: `$env:PYTHONUTF8=1` &nbsp;•&nbsp; Command Prompt: `set PYTHONUTF8=1`

**พอร์ต 5000 ถูกใช้อยู่**
เปลี่ยนเลขพอร์ตที่บรรทัด `app.run(...)` ท้ายไฟล์

## 10. ข้อจำกัดที่ควรทราบ

- ระบบตัดสินจาก **ข้อความที่ตัวรู้จำเสียงถอดออกมา** ไม่ใช่การวิเคราะห์คลื่นเสียงจริง
  จึงบอกได้ว่า "ออกเสียงจนฟังเป็นคำที่ถูกไหม" แต่วัดสำเนียงหรือระดับเสียงสูงต่ำไม่ได้
- ตัวแปลงหน่วยเสียงเป็น**กฎโฟนิกส์แบบประมาณ ไม่ใช่พจนานุกรมคำอ่าน** คำที่สะกดผิดกฎ
  (เช่น `have`, `said`) อาจแปลงเพี้ยน แต่ไม่กระทบคะแนนเพราะใช้กฎเดียวกันทั้งสองฝั่ง
- เสียงรอบข้างดังหรือไมค์คุณภาพต่ำจะทำให้คะแนนแกว่ง แนะนำให้ฝึกในที่เงียบ
- `app.run(debug=True)` เป็นเซิร์ฟเวอร์สำหรับพัฒนาเท่านั้น ถ้าจะใช้งานจริงบนอินเทอร์เน็ต
  ให้รันผ่าน WSGI server เช่น `waitress-serve --port=5000 app:app` และปิด `debug`
